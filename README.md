# Claude Code Tips — Daily Digest

Auto-refreshed digest of the most useful Claude Code workflow tips, harvested
daily from GitHub, Hacker News, and tech blogs.

**Live page:** https://zhisnoopy.github.io/claude-code-tips/

## How it works

```
┌─────────────────────────┐    ┌──────────────────────────┐    ┌─────────────────┐
│ GitHub Action           │───▶│ scripts/refresh-data.py  │───▶│ data/tips.json  │
│ runs daily 15:00 UTC    │    │  • fetch HN top stories  │    │ + index.html    │
│ (8 AM PT)               │    │  • fetch GitHub repos    │    │ (inlined JSON)  │
└─────────────────────────┘    │  • inline JSON into HTML │    └────────┬────────┘
                               └──────────────────────────┘             │
                                                                        ▼
                                                              ┌──────────────────┐
                                                              │ git commit+push  │
                                                              │ → GitHub Pages   │
                                                              │   rebuilds       │
                                                              └──────────────────┘
```

## File map

| Path | What it does |
| --- | --- |
| `index.html` | Single-page UI. CSS + render script + inlined JSON data block. |
| `data/tips.json` | The data. Has curated `themes` (manually written) + `trending_repos`/`trending_posts` (auto-refreshed). |
| `scripts/refresh-data.py` | Daily fetcher. Polls HN Algolia + GitHub Search API, rewrites `tips.json`, re-inlines into `index.html`. Stdlib only (no pip deps). |
| `.github/workflows/daily-refresh.yml` | GitHub Action that runs the script daily and pushes the result. |

## Editing tips

The seven curated `themes` (Context management, Plan first, etc.) and the 24
tips inside them are **hand-written** — they don't get auto-refreshed because
real distillation needs an LLM. To update:

1. Edit `data/tips.json` directly (look for the `themes` array).
2. Run `python3 scripts/refresh-data.py` locally to re-inline into `index.html`.
3. Commit and push.

## Editing the layout

Edit the `<style>` block or the render script in `index.html`. The inlined JSON
data block is bounded by these markers — leave them intact:

```html
<script type="application/json" id="data">
… (refresh script overwrites this section) …
</script>
```

## Triggering an off-schedule refresh

```bash
gh workflow run "Daily refresh"
```

Or from the GitHub UI: Actions tab → Daily refresh → Run workflow.
